## E1 게임 일지

게임 가이드, 뉴스, 팁, 업데이트를 위한 반응형 티스토리 블로그 스킨입니다.

## 소개

E1 Game Journal은 데스크톱과 모바일 기기 모두에서 깔끔하고 읽기 쉬운 경험을 제공하기 위해 만들어진 게임 정보 블로그 프로젝트입니다.

블로그 콘텐츠는 주로 한국어로 작성되며, 내비게이션과 인터페이스 라벨은 영어로 표시됩니다.

## 특징

- 모바일, 태블릿, 데스크톱에 최적화된 반응형 레이아웃
- 부트스트랩 5
- 밝은 테마와 어두운 테마 지원
- 리스트 스타일 게시물 레이아웃
- 카테고리 탐색
- 깔끔한 타이포그래피와 읽기 쉬운 콘텐츠
- 티스토리 스킨 템플릿 통합

## 프로젝트 구조

## E1 Game Journal

A responsive Tistory blog skin for gaming guides, news, tips, and updates.

## About

E1 Game Journal is a gaming information blog project designed to provide a clean and readable experience across desktop and mobile devices.

The blog content will primarily be written in Korean, while navigation and interface labels will use English.

## Features

- Responsive layout for mobile, tablet, and desktop
- Bootstrap 5
- Light and dark theme support
- List-style post layout
- Category navigation
- Clean typography and readable content
- Tistory skin template integration

## Project Structure

```text
E1-blog/
├── index.xml
├── skin.html
├── style.css
└── README.md
```

## Files

| File | Purpose |
| --- | --- |
| `index.xml` | Tistory skin metadata and default settings |
| `skin.html` | Blog layout and Tistory template markup |
| `style.css` | Responsive styling and theme colors |
| `README.md` | Project documentation |

## Technology

- HTML5
- CSS3
- Bootstrap 5
- Tistory skin template system
